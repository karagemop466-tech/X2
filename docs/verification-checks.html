Rules that produce the blank cells

  • Blank means not verified, never zero. An empty cell is a deliberate refusal to fill a number.
  • No inference from absence. A team missing from the injury report is not assumed healthy; bye status comes from the official schedule, not from the absence of a listing.
  • No market data was used. No odds, price, line or parlay payoff appears anywhere, because none was obtained from an authorised source.
  • Player string rank is left blank in every row, because no official source states it.

Every value on this site links to an official source or is marked blank/unverified; project implementation claims link to the repository. Research only. This is not betting advice.
