4. What this feed does not do

  • It publishes no return. It records outcomes, not prices, so it makes outcome grading computable and leaves monetary ROI blocked (Flags F07, F16); the summary file states this in the field roi_computable_against_market: False.
  • It is not the model's input. The feed and the backtest read the same transcribed finals; that shared origin is stated wherever a check uses it, because a feed cannot validate the transcription it was built from.
  • It keeps the LAR/LA alias visible — the standings and one schedule history use different abbreviations for the same club, so the reconciliation maps them to one club and says so (F55).
  • One tie is recorded among 1 settled games (week 5, Giants 27 at Commanders 27). It is kept as a tie rather than absorbed into a side; the consequence for the originated moneyline is recorded as F58.
