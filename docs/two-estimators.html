Every model total, published twice, until one wins

The rule. Keep both estimators visible with the gap column, and collapse to one only after a walk-forward comparison. The failure this guards against is premature collapse — choosing the construction that looked better in sample and then publishing only it. So the second estimator here is not a re-parameterisation of the first; it is built from a different quantity.

The three totals on every Week 11 game

  • A — structure. The published ridge attack/defence total: sum of a league mean, a home and an away offence term and a home and an away defence term, shrunk by a ridge penalty. Asserts that scoring and conceding are separable.
  • B — matchup experience. The mean of the two clubs’ own games-total averages, computed strictly from games before the week. No fitted parameter, no offence/defence split, no shrinkage.
  • C — the naive league constant. The reference total already published, included as a floor: an estimator that cannot beat a constant is not an estimator.

The pre-registered collapse rule, applied in order

The rule was written before the comparison ran and is applied in code order, not after the numbers were seen: E3 a difference counts only if the paired bootstrap 95% interval on the error difference excludes zero; E4 if no estimator is separable from the best other, the answer is “neither — keep publishing both”; E5 if one wins but its advantage over the naive constant is not established, keep publishing both.

The result is a negative one, and it is published as such. Over 89 walk-forward games the mean absolute errors are A = 11.08, B = 11.07 and C (the naive constant) = 10.96 points. The best point estimate is the constant, and no pair is separable: the A−B interval is -0.273 to +0.279 points, which contains zero, so rule E4 fires and the collapse gate stays open. Neither fitted estimator has yet shown it beats “these two teams’ games average about 46 points”. That is the honest reading of this sample size, and it is the reading that stops a lucky in-sample win from being promoted to “the model”.
