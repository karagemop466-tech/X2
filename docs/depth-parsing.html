Depth-chart parsing: the three structural failures, fixed mechanically

Why this page exists. A club depth chart is the only official-ish source for “who is the second-string left guard”, and it breaks a naive parser in three specific ways. Each one silently fabricates a starter if it is not handled, so each one now has a named test that fails the build. The worked example is the Green Bay Packers chart, read 2026-11-18 and self-labelled “Unofficial, Nov. 10, 2026”. Nothing on this page is a game-day claim about who starts.

1. Jersey-number prefixes

Green Bay renders every player cell as 9 Christian Watson. If the rank is read from the cell text, or a name list is sorted over the raw string, the “depth order” becomes a jersey order. The parser strips the number and keeps the raw string in raw_cell so the strip can be reviewed, and a test asserts that number + space + name reconstructs the raw cell exactly — which is what catches a regex that eats part of a name such as J. Michael Sturdivant.

2. Shared slots are groups, not a single starter

A depth slot is a list of rank-1 players. On this chart, 27 Kitan Oladapo appears at rank 2 in two different safety rows; league-wide the brief records 149 club/unit/position slots that name more than one rank-1 player. Treating column 1 as “the starter” invents a starter the club never named. The parser models a slot as a set, publishes the rank1_group_size, and names every co-starter when the group is larger than one. On the GB chart itself the group size is 1 for every slot; the guard is still enforced on the general case, and the table below shows the group size per slot.

3. Empty cells mean “nothing published”

32 cells are empty on this chart — Green Bay leaves the second and third receiver cells blank and the punt-returner first cell blank. An empty cell is not rank 0, not a bye and not “the position does not exist”. It is preserved as empty and counted per slot, never filled.

What this deliberately refuses to do

  • The Houston Texans image is not transcribed. The Texans publish the chart as a raster image (houstontexans.com/team/depth-chart renders an <img> under an “Unofficial Depth Chart” heading, with no player cells in the page text; www.texans.com/team/depth-chart returns 404). Reading names off pixels is the manual transcription the brief forbids. Test DP07 asserts that zero Texans cells exist in this repository.
  • No rank is inferred from jersey order, experience or salary. Test DP06 shows the rendered column order is not a jersey-number sort: only 5 of the 21 multi-player slots happen to be ascending, which is the evidence that column order carries information the jersey number cannot.
  • The club’s own “Unofficial” label travels with every row. A club chart is football-communications output, not a league depth order.
