Standing limitations

  • Single reviewer. This pass was performed independently of session 30beeb55's separate T15 check, and both found no discrepancies. Two independent passes are the strongest control the manual-transcription limitation allows, but neither is an automated diff (F10, F20).
  • Live pages move. Every "verified" statement is true of the page as read on 2026-11-14. The injury page shows no last-updated timestamp (F13).
  • Rights are not verification. Confirming a value matches NFL.com does not grant permission to republish it in bulk (F16).
  • Blank is deliberate. A dash means the official source did not supply a value, or no official source was found. It is never an inferred estimate.
