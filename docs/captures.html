Official captures and what changed

Read 2026-11-18. This page holds the dated official reads that replace the single 2026-11-14 snapshot. It publishes changes, not levels, wherever two reads exist. Each row links to the official page it came from. Nothing here is a prediction.

Not a scheduled capture. These reads were made by hand, one page request per chunk. The NFL.com Terms (Section 1.3) prohibit systematic retrieval to compile data without written consent, and gate D22 is not cleared, so no automated daily capture runs (see F98). The clock-time history the brief asks for therefore starts with two reads, not with a daily series.

Results register is behind the official standings (F96). The verified results feed holds 137 games (weeks 1-9 plus the Week 10 Thursday game). The 2026-11-18 standings reflect 13 more games played in Week 10 (Sunday and Monday), which are not in the frozen register.
