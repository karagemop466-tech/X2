Correlation provenance

Every correlation here names both of its inputs, the official page those inputs come from, and the n it was computed on. Each previously published value was recomputed from the official ledger before this page was built; the recomputation column records what happened, including where a published figure is rounded. The owner rule matters here: under the rule registered as F49 and applied in data/correlation_audit.csv, a correlation whose predictor is a model output is a diagnostic, not an officially sourced correlation, because the predictor is not itself an official number. The column below states, row by row, which inputs are official and which are model outputs, so that rule can be applied to any row without re-deriving it.

What is still not publishable as a correlation

  • Player-prop correlations. No player-prop outcomes, prices or settlement rules exist in this repository, so no prop correlation can be computed (F31).
  • Parlay-leg correlations beyond tickets. The two-leg study covers 24 tickets from a selected subset of games. It is published with its n and without an interval for that reason.
  • Anything built on a market price. With no odds feed, no correlation involving a price, a closing line or a return can be computed at all (F07).
