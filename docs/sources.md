## Source URL conventions used

- Injury report by week: `https://www.nfl.com/injuries/league/{YEAR}/REG{WEEK}`
  - Example: `https://www.nfl.com/injuries/league/2026/REG10` (2026 Week 10)
- Team roster: `https://www.nfl.com/teams/{team-slug}/`
  - Example: `https://www.nfl.com/teams/kansas-city-chiefs/`

## Non-official / third-party sources (flagged)

Depth charts listing 1st/2nd/3rd/4th-string backups are not published as a single official league page on NFL.com. Third-party depth-chart aggregators (e.g., nfl-depth-charts.com, sticktothemodel.com, thehuddle.com) were observed in search results but are NOT official NFL sources. Any depth-chart position values sourced from them are flagged unverified and must be re-checked against official NFL team roster pages before use.

## Betting lines & odds

The NFL does not publish official betting lines or odds. All lines, signals, parlay/prop constructions, validation gates, and correlation values in this project are original analytical work product, not official NFL data. They are labeled "analysis — not official source" throughout.
