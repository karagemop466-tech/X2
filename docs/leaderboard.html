Leaderboard — rules first, entries later

There is no leaderboard yet, and that is the correct state. A leaderboard with no validated entries would rank noise. The rules below exist so that when entries do arrive they cannot quietly reward luck. The requested reward for top performers is not defined or enabled: it is blocked by gate EG16 because contest and reward legality has not been reviewed for your jurisdiction.

What a first entry would require

  1. Written permission or a licence covering the data used (gate EG0).
  2. A preregistration committed before any evaluation (EG1).
  3. A point-in-time feature set that replays exactly (EG2).
  4. A declared baseline and metric, and a held-out block (EG3, EG5).
  5. Bootstrap and multiplicity-adjusted intervals (EG6).
  6. Real costs and settlement rules (EG7).
  7. A legal review of the reward itself (EG16).
