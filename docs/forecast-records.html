Forecast records: probability plus inputs, never a pick alone

Every stored output here is a probability together with the inputs that produced it and the residual scale that turned a number into that probability, so an output can be audited and replayed. The inputs are not descriptions: the same script re-derives each line from the documented construction and refuses to publish if the published number does not come back (tolerance is the published 1-decimal rounding).

No market price exists in this repository (F07, F51), so “covers” and “overs” are scored against the naive reference line the corpus is graded on, not against a bookmaker line. They are a benchmark-relative result, not a market edge. Personnel and availability features are not inputs: the model carries none, which is why the ablation the brief asks for is blocked (D24).
