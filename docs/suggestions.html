How to choose without guesswork

  1. Start at gate D01. Data rights block the largest number of suggestions. A written answer there changes several rows at once.
  2. Do not pick a statistics option before D02 and D03. Sample size and thresholds cannot be set responsibly before the market and the data exist.
  3. Legal before features. Resolve D09 before designing anything with a prize, referral or real-money element.
  4. Prefer the reversible option while a gate is open. Filtering and blank fields can be undone; publishing bulk data or defining a prize cannot.
  5. Log the choice. Record which option was chosen and why, so a later reviewer can see whether the decision still holds.
