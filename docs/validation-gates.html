Validation gates

A strategy may only be promoted if it clears every gate. The gates exist to separate skill from luck: no look-ahead, enough sample, a significant and stable accuracy gain, uncertainty that excludes zero, control for testing many strategies at once, and a record that a sign-shuffle cannot reproduce. The numeric cut-offs below are proposed by this session and are not yet approved by the project owner (Flag F17).

How luck is removed

  • Walk-forward only (G1). Ratings for a week never see that week's results, so hindsight cannot leak into the score.
  • Permutation tests (G3, G7). The sign of each bet and of each paired accuracy difference is shuffled thousands of times. If random shuffling often reproduces the observed gain, the gain is not evidence.
  • Bootstrap intervals (G5). Resampling the games themselves shows how much of the gain is sampling noise; the interval must exclude zero.
  • Multiple-comparison control (G4). Seven strategies were tested, so raw p-values are adjusted with Benjamini-Hochberg. Testing many ideas guarantees a lucky winner; this is the tax on doing so.
  • Stability (G6). The gain must appear in both halves of the window, not in one hot streak.
  • Required sample size. Each row on the leaderboard states how many bets it needs for an 80%-power test. This is the honest answer to "is it proven yet": mostly, not yet.

None of this removes variance from football. It only prevents variance from being mistaken for skill. NIST on multiple-comparison risk ↗ · NIST on bootstrap intervals ↗
