Selectivity: does a bigger projection mean a more reliable game?

This is the practical "remove luck" test. If a rule's largest projections were genuinely better, acting only on them would improve accuracy. Each band is scored against predicting no margin for the same games, so a positive value means the rule helped inside that band. Result: for six of the seven rules with a spread of projection sizes, the 3-to-7 point band beat the under-3 point band — but the largest bands hold only a handful of games and swing negative. That is suggestive, not established: read the game count in each band before reading the number.

What the correlations say about parlays

  • The two teams' scores in the same game show no measurable dependence on this sample, and the game total shows no measurable relationship with how lopsided the game was. That is a warning, not an all-clear: the intervals are wide because the sample is 137 games.
  • Combining legs from different games does not remove the shared week and season context, and combining legs within one game adds dependence this project has not measured for player props. No parlay price, joint probability or settled parlay outcome is available here, so no parlay expectation is published.
  • Model redundancy is real and large. Two structurally different margin models (S3 and S5) have almost perfectly correlated errors. Stacking similar models does not diversify anything; it repeats the same mistake.
