Demotion gates

A gate written down but never evaluated is not a control. The proposed conditions are on Market tables; this page runs each of them against measured numbers for every strategy on the board, so a threshold can be argued about with a number beside it. No strategy is live today, so nothing is demoted — the verdict column says what the rule would do.

1. Triggers, and what each one is for

D7's "closing line value worse than zero for two consecutive windows" is kept not computable: there is no closing market line at all (Flags F07, F16), and an unmeasurable rule must not read as a passed one. Two triggers added here are labelled as new so they are not mistaken for the owner's list: D8 (the results feed has not updated within its window) and D9 (a market reached kickoff with no closing capture).

3. What the numbers say

  • D1 as drafted fires on all four ridge variants. Over the most recent 50 out-of-sample games the mean advantage over the reference line is positive for every one of them (M1: mean advantage +0.74 points, 95% interval [-0.52, +1.96] (reference absolute error - m1_spread_home absolute error (matches the published m1_error column to 0.00 points, so the recomputation is equivalent))), but each 95% bootstrap interval includes zero, so a rule of "lower bound above zero" demotes the whole board. A gate that always fires distinguishes nothing — this is decision D13 and suggestion S34, and it agrees with session 8a0bf37e's independent window check.
  • D2 reproduces the published q-values exactly. Adjusting over the 6 strategies that have a skill test gives the numbers the leaderboard publishes; adjusting over all 7 rows would raise every q by 1.1667 times. Both conventions give the same verdict today, and the convention is now recorded rather than assumed (Flag F56).
  • D5 already fires. The rights and jurisdiction flags that suspend a strategy are open, so every row fires — correct behaviour for a suspend-first gate, and a reminder that the statistical gates sit downstream of an unresolved legal question (Flags F16, F09, F19).
  • D6 cannot fire by construction, and that is the design. Units, drawdown and streaks are written to a file the ranking step never reads, so no staking run can move a rank; the check measures the resulting order rather than trusting the intention (Staking ledger).
