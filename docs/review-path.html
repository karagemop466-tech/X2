Review path — pick a direction before anything is built

This page exists so one reviewer can choose a route through the project's open items, in order, with the evidence for each step in front of them. Nothing on this page is implemented, enabled or approved. It is a reading order, not a plan of record. The registers behind it are the Suggestions matrix, the Decisions register, the Questions page and the Flagged for review page.

The short version

  • What the project can defend today: an independently originated spread and total for each Week 11 game, a walk-forward out-of-sample record against a naive reference line, correlations with intervals and sample sizes, and a line-by-line verification record.
  • What it cannot do yet: any market comparison, return on investment, staking result, player-prop number or strategy reward. Every one of those needs a licensed price source or player-level data that the project does not hold.
  • The one thing to decide first: step 1. Rights and legal position gate more rows than any other choice, and they are the least reversible if ignored.
  • The one number to read carefully: the model beats its naive reference line, but the naive reference line is not a sportsbook. Beating it is not evidence of beating a market.

How to use this page

  1. Do not choose a later step while an earlier one is open. Step 2 has no meaning without step 1, and step 6 cannot be measured without step 2.
  2. Prefer the option that can be undone. Blank columns and inert gates cost nothing to keep; a published return or an enabled reward does.
  3. Ask for the sample size, not the result. Every ranking on the site states the number of forecasts it needs for a decisive test. If that number is far above the games played, the ranking is provisional no matter how it reads.
  4. Treat a blank as a finding. Where a value is blank, the source did not support it. That is the intended state, not an omission to be filled in by inference.
  5. Record the choice and the date. A decision without a recorded date cannot be re-checked later, because the evidence underneath it will have moved.

Every value on this site links to an official source or is marked blank/unverified; project implementation claims link to the repository. Research only. This is not betting advice.
