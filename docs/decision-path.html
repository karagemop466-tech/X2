What must be answered before any decision

This is the short list of information gates that block progress. Every item below is currently open. Each one needs a written answer from a named owner before a dependent choice can reasonably be made. Ordering matters: a later gate cannot be resolved with confidence while an earlier one is open. Nothing on this page is a legal or statistical conclusion; each row links to the official source that defines the constraint.

Why luck cannot simply be removed

The brief asks to remove luck and build signals that are selectively skill based. Football outcomes contain genuine randomness, and a finite sample of games contains noise that no method can delete. The defensible version of the request is: pre-register the test, score against an explicit noise baseline, report uncertainty, and only then rank. Those steps are gated by D07, D08 and D10 above.
