Why luck cannot simply be removed

The brief asks to remove luck and build signals that are selectively skill based. Football outcomes contain genuine randomness, and a finite sample of games contains noise that no method can delete. The defensible version of the request is: pre-register the test, score against an explicit noise baseline, report uncertainty, and only then rank. Those steps are gated by D07, D08 and D10 above. See the Strategy lab for the gate framework and the Suggestions page for the paths that depend on each gate.
