Price-snapshot store

What this store is. Every market this project originates — the side, the total and the moneyline, for the Week 11 slate and for the out-of-sample backtest window — has one row here, recording the opening number and the closing number that the market published for it. Every opening and closing value is blank and flagged. This project has no licensed odds feed, and no official free source publishes opening or closing NFL market numbers, so no value can be confirmed from an official source and none is inferred (Flags F07, F31, F51). The store is built so that, the moment a rights-cleared official odds source is connected, the numbers drop straight into the existing columns. The fair line column is the model's own originated number and is first-party computed; it is not a market price.

How to read the columns

  • fair_line — the model's originated number for that market (side spread, total, or fair moneyline). First-party computed from official results; not a market price.
  • opening_number / closing_number — the market's opening and closing numbers. Blank by design: no official source confirms them (F07, F31, F51).
  • opening_verified / closing_verified — No for every row, because no value is filled.
  • status — carries the flag text on every row so the blank is never read as an omission.
  • Which half of the store this is (session f25d6b55). fair_line is our own opening number for every market we originate: for the out-of-sample window (weeks 4–10) it is the walk-forward pre-game prediction, fitted only on games played strictly before that week; for Week 11 it is the origination-run value recorded 2026-11-14. The close of our own fair line is not yet recorded separately, and the market open/close cells stay blank until an authorised source is connected (F07; flag F51 covers the same condition on the Week 11 store). A fixed snapshot cadence (origin, weekly interim, close at kickoff) is proposed in suggestion S32.
  • Flag numbering note (F63). The session that built this store cited “F45” and “F46” for the blank opening/closing values, but those IDs belong to a different register section (depth charts and the signal/staking split). The conditions are covered in the register by F07, F31 and F51; F63 records the misreference so the Flagged page stays accurate.
