# Requirements

The complete list of requirements the X2 NFL lines system must satisfy, grouped by
category. Each requirement is cross-referenced to the official or methodology source
that grounds its factual basis.

## Data & Collection

The system must collect a complete, current set of inputs before any analysis.
Sources are the official NFL feeds plus confirmed references for odds.

## How to use this list

- **Data & Collection** requirements define the inputs the system must gather
  automatically, with no manual entry.
- **Strategy & Signals** requirements define the signal types the system must
  generate (single bet, parlay, player prop).
- **Validation & Skill** requirements define how a strategy is proven to be skill-
  based rather than lucky before it is accepted or ranked.
- **Injuries & Depth** requirements define the injury and backup-replacement
  tracking the user explicitly requested.
- **Site & Presentation** requirements define the dashboard and its content.
- **Process & Governance** requirements define the decision framework, verification
  rule, and coordination.

Any requirement whose source is a methodology reference (rather than an official
NFL page) is labeled as such on the [Data Sources](../data-sources/) page. Values
that depend on a feed that is not yet connected are captured as open questions and
suggestions rather than assumed.
