Snap-count source evaluation — does an official source exist?

Why: the brief conditions the playing-time depth route on it — “derive depth from snap counts if an official snap-count source exists”. This page records one verdict row per official source tried, read live on 2026-11-19 by session cb679d0e. No third-party numbers were used or consulted.

Verdict: an official snap-count source EXISTS. The league's public stats surfaces (player stats, team stats, Next Gen Stats, Football Operations) do not publish snap counts, but every official Game Book (PDF) carries a Playtime Percentage section with per-player snap counts and shares by phase (Offense / Defense / Special Teams). Confirmed in 2 of 2 sampled Game Books (WAS@NYG 11/12/2026; KC@ATL 11/15/2026). Three caveats: (1) Game Books publish after the game, so this supports retrospective depth/playing-time analysis only, never a pre-game lineup call; (2) the Game Book header restricts use beyond media coverage to written NFL permission, so systematic capture stays gated by the open rights review (F16); (3) coverage here is 2 games — presence in every Game Book is indicated, not proven. See flag F134.
