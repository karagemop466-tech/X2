# Suggestions

Proposed improvements to the site and the system, intended for review. **No
suggestion is implemented until it has been reviewed and the best path is chosen.**
Each suggestion targets either a missing piece of information needed for a decision
or an improvement to decision-making. Use this page to review and select the path
forward before any change is made.

## Review process

1. Review each suggestion against the open questions on the
   [Questions & Answers](../questions-and-answers/) page.
2. For each open question, select the suggestion that supplies the required
   information, and record the chosen path.
3. Prioritize suggestions marked **High** impact — these are the gates to live
   decision-making (CLV feed, stats endpoint, depth monitor, CLV-based ranking).
4. Do not implement a suggestion until its decision is recorded. Flagged
   irregularities and unverified items do not block the site, but they are
   resolved only through this review.
