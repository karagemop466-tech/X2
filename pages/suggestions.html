Suggestions — dedicated review section

A dedicated section so someone can review suggestions and choose the best path before implementing any changes. No suggestion is implemented until reviewed here and approved via the Decision Framework.

Review process: submit a suggestion → reviewer assesses it against the Decision Framework questions → approve, request revision, or reject → approved changes are implemented and logged in COORDINATION.md.

Before any change is implemented

Every suggestion must pass these checks (from the Decision Framework):

  • The relevant gate questions are answered (information we have vs. information we lack).
  • All data values are linked to an official source, or left blank and flagged unverified.
  • The change is logged in COORDINATION.md with sources and verification performed.
  • Strategy changes additionally pass validation gates G1–G6 (see Strategies & Signals).
No manual input is required to read this site. To contribute a suggestion, edit pages/suggestions.html (or open an issue/PR) and assign yourself as owner in COORDINATION.md.
